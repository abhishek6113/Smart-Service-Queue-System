# Smart Service Queue Optimization System

A C++-based project designed to demonstrate service queue management and prioritization, with a web interface built using HTML, CSS, and JavaScript.

## Live Demo

[https://smart-service-queue-system.onrender.com](https://smart-service-queue-system.onrender.com)

## Features

- Add customers to the service queue.
- Manage queue entries through a web interface.
- Demonstrate priority-based service queue concepts.
- Simple and user-friendly interface.
- Online deployment using Render.

## Technologies Used

- **C++** — server and queue-related programming
- **HTML5** — webpage structure
- **CSS3** — styling and layout
- **JavaScript** — frontend interactions
- **Git & GitHub** — version control and source code hosting
- **Render** — server deployment

## Project Files

- `index.html` — webpage structure
- `style.css` — webpage styling
- `script.js` — frontend functionality
- `queue.cpp` — queue implementation
- `server.cpp` — C++ web server
- `Dockerfile` — deployment configuration

## Run Locally

1. Clone this repository.
2. Install a C++ compiler that supports your operating system.
3. Compile and run the server using the appropriate commands for your platform.
4. Open the local server address in your browser.
